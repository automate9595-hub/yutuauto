YUTU WORKER
1) En la web: "Exportar cola para el worker" (baja yutu-studio-cola.json).
2) Ejecuta 2-INSTALAR-Y-EJECUTAR.bat (toma ese archivo de Descargas).
3) Subida a YouTube: pone client_secret.json (OAuth "Aplicacion de escritorio",
   YouTube Data API v3) en esta carpeta. La primera vez abre el navegador.
   Los videos quedan programados (privados hasta su hora).
Nota: proyectos de API sin auditar fuerzan los videos como privados. Solicita la
auditoria en Google Cloud si no se publican solos.
